4. Technical Analysis & The Three Sentences on Token Referencing:
- When a component or color role is hardcoded directly to a raw hex code rather than referencing a primitive token alias, it severs the automated cascade linking design intent to code.
- Changing the brand primary color at the source successfully updated the primary container to the new emerald palette, but the unlinked Pay button remained stranded on the obsolete royal blue, instantly destroying brand harmony and visual cohesion.
- Token referencing is the only mechanism that ensures a single change at the source of truth propagates predictably throughout the entire system without requiring error-prone manual audits across individual component files.
