The SMTP configuration failed because an ordinary personal/account password was used instead of an Application-Specific Password. In May 2022, Google disabled "Less Secure Apps" (basic authentication with account passwords). Any automated server SMTP delivery through Google Mail requires two-factor authentication to be enabled and a dedicated 16-character App Password generated.

The Fix:
1. In production: Configure 2FA on the school's Google Workspace administrator account and generate a 16-character App Password stored strictly in the environment variable `SMTP_PASS`.
